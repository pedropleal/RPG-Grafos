T2 — UVA 796 Critical Links — Catálogo de casos de teste

Os resultados da execução estão em testes/resultado-local.md.
Este catálogo não constitui evidência de Accepted.
Para executar de uma vez os casos do grupo, usar dados/entrada.txt
e comparar com dados/saida-esperada.txt.

Formato da entrada (cada caso):
  n
  u (k) v1 v2 ... vk      <- n linhas, uma por servidor (vértices de 0 a n-1)
A entrada termina no fim do arquivo (EOF). n = 0 é uma rede vazia, não um terminador.

Formato da saída (cada caso):
  X critical links
  a - b                   <- uma linha por ponte, com a < b, em ordem crescente
  (linha em branco)

Observação: cada saída termina com uma linha em branco, conforme exige o problema.
